## Token grammar, checked by hand

Since both notes are v1, `lint-scope.sh`'s token-grammar pass never reads
either of them (v1 files are lint-exempt entirely, confirmed by reading the
script: it just increments a v1 counter and moves on). So I grepped every
bracket above the `## Raw Content` fence in both notes myself. The only
bracket-shaped tokens present are two `[memory candidate: project]` /
`[memory candidate: client]` lines in note one (rows 1-2 of the ten-row table)
and the checkbox syntax `- [ ]` in both notes' Action Items (not a token: the
grammar's bracket regex requires a lowercase-letter start inside the
brackets, and a bare space doesn't qualify — same convention `old-only`
relies on). No other bracketed tokens are used anywhere in the fixture,
including the two `_memory` records, which use no bracket syntax at all.

Ran `lint-scope.sh` over the fixture regardless (exit 0, 4 v1 files, 0 v2) —
per the task's own instruction this only confirms structural sanity
(frontmatter fences/links), not token grammar, since it's scoped to `schema: 2`
files.
