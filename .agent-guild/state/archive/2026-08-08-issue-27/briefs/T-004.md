## Spec excerpt

Add one section to `tests/inbox-to-memory-smoke.sh` that tests the real `stamp-confirmed.sh` (T-001, already shipped). This is the section that carries the issue's seventh and hardest acceptance criterion: *the smoke test asserts that a run over the mixed fixture leaves v1 records untouched.*

That criterion is why this feature has a script at all instead of living in prose. A section of `require_text` calls confirming SKILL.md contains the words "V1 records are skipped entirely" would turn the suite green and test nothing, and it is the specific outcome the design exists to prevent.

### What to assert, at minimum

Each on its own copy of a fixture under `mktemp -d`, each registered for cleanup:

- **The headline.** A run over a copy of `mixed/` leaves `_memory/decisions/freeze-window-owned-by-ops-ocPwdpeY0a.md` byte-identical (shasum before and after) while `_memory/context/atlas-region-topology-mPmy8XBe5H.md` moves to the note's date.
- **Backward and equal.** A note dated 2025-12-02 and one dated exactly 2026-02-10 both leave the record at 2026-02-10.
- **The cross-group dedupe.** Two `--note` groups naming the same record in one invocation produce one write and one output line — the issue's "confirmed twice in one run."
- **The status gate.** A record mutated to `status: proposed` is skipped.
- **Key insertion.** A v2 record with `last_confirmed` removed gains it in contract position, and the scope still lints clean.

The suite's whole-fixture hash guard is a **pair**: it snapshots at `:586` and compares at `:1299`. Only writes between those lines are caught. Your section goes between them. Above the snapshot it is baked into the baseline; below the comparison it is invisible to the guard, and appending at the end of the file is both the natural instinct and wrong.

The name is pinned because the placement check locates the binding by it.
3. Every invocation goes through `"$stamper"` on a plain line or captured into a variable, as `out="$(bash "$migrator" …)"` already does. **Never inside an `echo` or a `require_text`** — the placement check excludes both, so an invocation wrapped in one is invisible to it.
