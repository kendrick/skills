write into `tests/fixtures/`, and each scope's `mktemp -d` is immediately
followed by a full `EXIT` trap re-listing every path from the trap before it
(the existing one at the old `:1203`) plus the new path — the second trap
carries the first trap's list plus the first scope's own path too.

Injection is done via a small `inject_above_fence()` helper (python3 heredoc,
mirroring the technique the constitution's own C-2/C-3 check scripts use)
that splices a text block in just above `## Raw Content`, since `extract_body`
stops there and content below it is invisible to `check_links`.

awkward possessive), since the prose was already plain and technical.
